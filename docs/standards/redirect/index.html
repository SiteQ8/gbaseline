هل يُحوَّل الزائر إلى HTTPS إذا كتب العنوان دون تشفير؟

لماذا يهم

يكتب الناس العناوين دون تحديد البروتوكول فيخرج الطلب الأول غالباً دون تشفير لذلك يمنع التحويل الفوري إلى HTTPS قراءة تلك الزيارة الأولى أو تعديلها في الطريق.

متى يجتاز النطاق

يجتاز الموقع عندما يحوّل HTTP إلى HTTPS أو عندما لا يقدّم HTTP أصلاً.

كيف تعالجه

  1. أجب عن كل طلب HTTP بتحويل دائم إلى المسار نفسه عبر HTTPS.
  2. ثم أضف HSTS حتى يتخطى المتصفح الطلب غير المشفر في المرات التالية.
