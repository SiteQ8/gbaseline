Does typing the plain address end up on HTTPS?

Why it matters

People type addresses without a scheme, so the first request often leaves unencrypted. Redirecting it straight to HTTPS keeps that first visit from being read or rewritten on the way.

When a domain passes

Passes when plain HTTP redirects to HTTPS, or when plain HTTP is not served at all.

How to fix it

  1. Answer every plain HTTP request with a permanent redirect to the same path over HTTPS.
  2. Then add HSTS so the browser skips the plain request next time.
