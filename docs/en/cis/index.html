What can be seen from outside for each CIS Controls v8.1 safeguard, measured across the public domains of the Arabian Gulf, as visible evidence for the safeguard and not a full assessment of it.

CIS Controls

This page ties what the baseline measures to the CIS Controls many organisations in the Arabian Gulf work with, so each team reads its state's figures in the language of the framework it already uses.

CIS Controls in the Arabian Gulf

Each figure is the share meeting the visible evidence, and it does not mean the safeguard is met, since most of what it asks happens inside and cannot be seen from outside.

  1. 9.5 Implement DMARC

    Implementation Group 2 CIS 9 Email and Web Browser Protections

    • 19.3% DMARC enforced 2,663 of 13,797
    • 70.1% SPF in place 9,675 of 13,798

  2. 3.10 Encrypt Sensitive Data in Transit

    Implementation Group 2 CIS 3 Data Protection

    • 91.2% Valid HTTPS 10,791 of 11,830
    • 18.5% HSTS for a year or more 2,185 of 11,830
    • 86.9% TLS 1.3 supported 10,284 of 11,830
    • 69.5% No TLS 1.0 or 1.1 7,968 of 11,472
    • 52.5% Post quantum ready 6,206 of 11,826
    • 0.5% MTA-STS enforced 52 of 10,871

  3. 16.2 Establish and Maintain a Process to Accept and Address Software Vulnerabilities

    Implementation Group 2 CIS 16 Application Software Security

    • 1.9% security.txt published 224 of 11,824

  4. 2.2 Ensure Authorized Software is Currently Supported

    Implementation Group 1 CIS 2 Inventory and Control of Software Assets

    • 76.4% Announce a version still supported 2,726 of 3,570 websites

  5. 7.4 Perform Automated Application Patch Management

    Implementation Group 1 CIS 7 Continuous Vulnerability Management

    • 84.9% On the latest release of their support cycle 3,031 of 3,570 websites

  6. 7.7 Remediate Detected Vulnerabilities

    Implementation Group 2 CIS 7 Continuous Vulnerability Management

    • 71.6% Announce no version hit by an exploited vulnerability 1,510 of 2,108 websites
