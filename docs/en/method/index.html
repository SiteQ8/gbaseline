What is measured

Every registrable domain under the government, education, health, business, non-profit and network suffixes of the six Arabian Gulf states is measured, each counted once as an organisation rather than every host beneath it. The military, embassy and personal suffixes are left out.

Where the names come from

Names come from public Certificate Transparency logs, read through crt.sh, and from the Tranco list of popular sites. A name stays in the inventory once seen, and each issue counts only the names that still exist in DNS.

How the measurement runs

DNS is read over HTTPS through two public validating resolvers, Cloudflare and Google, and a DMARC answer counts only when both agree. Websites and TLS are probed with ordinary single requests from a runner hosted by GitHub, with a user agent that links back to this page. Anything inconclusive is then measured again later in the same run, and a broken DNSSEC result stands only when it is seen twice.

What is published and what is not

Each issue publishes totals by country, sector and check, the weekly series and the open data. No domain is named, and no list or ranking of organisations is published, while anyone can check a single domain live.

Limits

The weekly scan runs outside the Arabian Gulf, so a site that blocks foreign traffic is counted as unreachable and left out of the web checks, never counted as failing. DKIM is not measured, because its selectors cannot be listed from outside. Domains registered directly under a country code, or under global extensions such as .com, are not included yet.

A share is the passing domains divided by the domains where the check applies and could be measured.

How to cite the figures

Give the issue number and its date, so readers can find the exact figures you used.

Every figure has a citation in Arabic and English whose link opens the issue it comes from, and every issue has a reference and a BibTeX entry, given below for the latest one.

Ali AlEnezi (2026). Gulf Cybersecurity Baseline, issue 2, 19 October 2026. https://gbaseline.3li.info/en/issues/2/

علي العنزي (2026) خط الأساس الخليجي للأمن السيبراني العدد 2 الصادر في 19 أكتوبر 2026 https://gbaseline.3li.info/issues/2/

@misc{gbaseline-issue-2,
  author = {AlEnezi, Ali},
  title = {Gulf Cybersecurity Baseline, issue 2},
  year = {2026},
  date = {2026-10-19},
  url = {https://gbaseline.3li.info/en/issues/2/},
  note = {An open weekly measurement of how well the public domains of the six Arabian Gulf states protect email, DNS and the web, published as totals anyone can quote with a live check for any single domain}
}

Command line and MCP server

The same engine runs the full check of any domain from your own machine and answers AI assistants through MCP.

npx -y github:SiteQ8/gbaseline check example.com
npx -y github:SiteQ8/gbaseline check example.com --lang ar --json
{
  "mcpServers": {
    "gbaseline": {
      "command": "npx",
      "args": [
        "-y",
        "github:SiteQ8/gbaseline",
        "mcp"
      ]
    }
  }
}
